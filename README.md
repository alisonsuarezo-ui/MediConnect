MediConnect Telegram

Descripción

MediConnect Telegram es un sistema automatizado para la gestión de citas médicas mediante un bot de Telegram. Permite agendar citas, consultarlas y recibir recordatorios automáticos.

Tecnologías Utilizadas

Telegram Bot API
n8n
Google Sheets
OpenRouter AI
JavaScript
Funcionalidades

Agendar citas médicas.
Consultar citas registradas.
Recibir recordatorios automáticos.
Clasificación inteligente de solicitudes.
Flujo del Sistema

Usuario → Telegram → n8n → IA → Google Sheets → Respuesta automática

Conclusión

MediConnect optimiza la gestión de citas médicas mediante automatización e inteligencia artificial, mejorando la atención y organización de los pacientes.
